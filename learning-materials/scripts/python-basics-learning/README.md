## 三、建议学习路线

总共约 6 个学习单元，每个 40–60 分钟：

```
01 变量   →  02 运算符  →  03 表达式  →  04 流程控制  →  05 函数  →  06 综合练习
   ↑ 打地基      ↑ 会算数      ↑ 会表达      ↑ 会控制逻辑     ↑ 会抽象     ↑ 检验成果
```

每个文件的五步学法：

1. **盲跑一遍** —— 不读注释，直接运行，先看输出，猜猜每段在干什么；
2. **回头精读** —— 对着注释逐节读，重点看 `# ⚠️ 坑：` 标记的地方；
3. **动手改** —— 把数字、字符串、条件改掉，再跑一次，看输出怎么变（**这一步最关键**）；
4. **自己做练习** —— 翻到文件末尾，先不看答案，自己写；
5. **对答案** —— 三引号里的参考答案只是文本、不会执行，对比思路而不是死记写法。

学完 05 之后再做 06 的综合练习，效果最好；也可以每学完一章就做 06 里对应的那一部分。

## 四、各章要点速查

### 01 变量
- 变量不是「装值的盒子」，而是**贴在对象上的名字**——用 `id()` 可以亲眼验证。
- 赋值的两件事：先算右边得到对象，再让左边的名字指向它。
- `is` 比的是**是不是同一个对象**，`==` 比的是**值是否相等**；判断 `None` 一律用 `is None`。
- 小整数缓存（−5 ~ 256）与字符串驻留是**实现细节**，别拿 `is` 判等。
- 可变对象（list/dict/set）的别名陷阱：`b = a` 改一个会连带改另一个，要隔离就用 `copy.deepcopy()`。

### 02 运算符
- `/` 永远返回 float；`//` 是**向下取整**（`-7 // 2 == -4`）；`%` 的符号**跟随除数**（`-7 % 3 == 2`）。
- `and` / `or` 返回的是**操作数本身**，不是 `True`/`False`——这就是 `x = y or "默认值"` 能用的原因。
- `and` / `or` 优先级**低于**比较运算符，且会**短路求值**（右边可能根本不执行）。
- 增强赋值 `+=` 对列表是**原地修改**（id 不变），`lst = lst + [...]` 则是新建对象。
- 海象运算符 `:=` 能在表达式里赋值，但优先级很低，习惯上要加括号 `(n := 10)`。

### 03 表达式
- 表达式**一定有值**，语句不一定——这是两者的分界线。
- f-string 是格式化首选：`{x:.2f}` 两位小数、`{x:>10}` 右对齐、`{x:,}` 千分位、`{x=}` 调试打印。
- 切片 `s[start:stop:step]` 左闭右开、越界不报错、`s[::-1]` 一步反转。
- 推导式把循环 + 过滤 + 构造合成一行；生成器表达式 `(x for x in ...)` 是惰性的，省内存。
- 所有「假值」：`0` `0.0` `""` `[]` `()` `{}` `set()` `None` `range(0)`——所以「空列表」当条件为假。

### 04 流程控制
- 缩进就是语法，标准 4 空格；Tab 与空格混用会 `IndentationError`。
- `elif` 顺序很重要，把宽条件写前面会让后面的分支永远走不到。
- `for` / `while` 后面的 `else`：循环**正常结束**才执行，被 `break` 打断就不执行——用来省掉标志位变量。
- `break` 只跳出**当前这一层**循环；想跳出多层用函数 `return` 或 for-else。
- `range(a, b)` 左闭右开；`zip` 按最短截断；`enumerate` 的 `start` 参数可指定起始编号。
- `match-case` 是 3.10+ 的结构模式匹配，能匹配字面量、`|` 多值、解包、加 `if` 守卫。

### 05 函数
- 函数是**一等对象**：能赋值给变量、放进列表、当参数传、当返回值返回。
- 参数顺序规则：位置 → `*args` → 默认值 → 仅关键字 → `**kwargs`；`*` 后强制关键字传，`/` 前强制位置传。
- 没写 `return` 就返回 `None`；`return a, b` 其实返回的是元组。
- **可变默认参数的大坑**：`def f(x, lst=[])` 的默认值只在定义时创建一次，会跨调用累积——改成 `lst=None` 再在函数体内判断。
- 作用域查找顺序 **LEGB**（Local → Enclosing → Global → Builtins）；函数内给同名变量赋值会让它变成局部变量，于是外部那个用不了（`UnboundLocalError`）。
- 装饰器本质是「接收函数、返回函数」；写装饰器记得加 `functools.wraps` 保留原函数信息。

## 五、常见报错对照表

| 报错 | 典型原因 | 怎么修 |
|---|---|---|
| `SyntaxError` | 少括号 / 少冒号 / 中文标点 / `if a = 1` | 看箭头指向的那一行**上一行**结尾 |
| `IndentationError` | Tab 与空格混用、缩进层级不对 | 统一用 4 空格重排 |
| `NameError` | 变量名打错、用了还没赋值、函数外访问函数内变量 | 检查拼写与作用域 |
| `UnboundLocalError` | 函数内给某名字赋值，又在赋值前读它 | 用 `global` / `nonlocal`，或换个变量名 |
| `TypeError` | 类型不匹配：`"1" + 1`、参数个数不对 | 用 `type()` 确认类型，`int()` / `str()` 转换 |
| `ValueError` | 类型对但值不对：`int("abc")`、解包个数不匹配 | 检查数据本身 |
| `IndexError` | 下标越界（`range` 左闭右开常少一次） | 打印 `len()` 核对边界 |
| `KeyError` | 字典里没这个键 | 用 `.get(k, 默认值)` 或 `in` 先判断 |
| `AttributeError` | 方法名拼错、对 `None` 调方法 | 确认对象的类型与拼写 |
| `ZeroDivisionError` | 除数为 0（含 `//` `%`） | 先判断再除 |
| `RecursionError` | 递归忘了终止条件 | 检查 base case，或用循环改写 |

## 六、注意

- 六个脚本**互不依赖**，可以任意顺序打开、单独运行。
- 文件里 `id()` 打印的内存地址每次运行都可能不同，只需比较**两次是不是同一个数**。
- 小整数缓存、字符串驻留属于 CPython 实现细节，不同版本/不同解释器表现可能不同，不要写进正式逻辑。
