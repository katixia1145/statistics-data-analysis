# 概念学习资料生成 Skill (Concept Learning Material Generator)

## 概述
这是一个通用的概念学习资料生成工具，能够根据用户指定的**任意领域主题或概念**，自动生成结构化的学习资料，包括定义、机制、示例、应用场景等。

**核心理念**：将任何复杂概念转化为易于理解的学习材料，强调真实性、可核查性和实用性。

---

## 一、适用场景

此 Skill 适用于以下场景：

### 1.1 主要使用场景
- 📚 **学习全新概念**：当用户遇到陌生的专业术语或理论时
- 🔍 **深入理解已知概念**：当用户想系统性地掌握某个概念的方方面面
- 📝 **整理学习笔记**：将零散的知识点组织成结构化文档
- 🎯 **备考复习**：为考试准备重点概念总结
- 💼 **工作应用**：快速了解工作中需要的专业概念
- 🔄 **跨领域学习**：学习非本专业的概念（如程序员学统计学，统计学家学AI）

### 1.2 支持的领域范围
- ✅ **不限领域**：可以处理任何学科的概念
- ✅ **技术类**：AI、机器学习、数据科学、软件工程、统计学
- ✅ **商业类**：管理学、经济学、市场营销、金融
- ✅ **学术类**：物理学、生物学、心理学、社会学
- ✅ **通用类**：方法论、思维模型、软技能

---

## 二、输入信息要求

### 2.1 必需输入
用户必须提供：
- **概念名称**：想学习的具体概念（中文或英文）
- **可选**：指定领域背景（如"在AI领域中的Agent"）

### 2.2 输入示例
```
✅ 正确输入：
- "帮我学习 Agent 这个概念"
- "解释一下 LLM Context 在大语言模型中的作用"
- "生成 Skill 的学习资料"

❌ 错误输入（缺少目标概念）：
- "帮我学习一些东西"
- "给我讲点知识"
```

### 2.3 触发条件
当用户提出以下需求时触发此 Skill：
- "帮我学习XXX概念"
- "生成XXX的学习资料"
- "解释一下XXX是什么"
- "我想了解XXX知识点"
- "整理XXX的学习笔记"
- 任何包含具体概念名称的解释请求

## 三、生成步骤（严格遵循）

### Step 1: 概念识别与分析 ⏱️ 预估时间：30秒
**操作**：
1. 提取用户提到的核心概念名称
2. 判断概念的领域归属（如AI、统计学、管理学）
3. 评估概念的复杂度等级（初级/中级/高级）
4. 确定是否需要拆分为子概念

**输出**：概念分析卡片
```
概念: [名称]
领域: [所属领域]
复杂度: [初级|中级|高级]
相关子概念: [如有]
```

### Step 2: 信息检索与验证 ⏱️ 预估时间：2-3分钟
**操作**：
1. 从权威知识源检索该概念的定义和解释
2. **必须交叉验证至少2个独立来源**
3. 收集核心机制、组成要素、工作原理
4. 寻找实际应用案例
5. 识别常见误区和边界条件

**资料来源要求**（详见第六节）

### Step 3: 内容结构化组织 ⏱️ 预估时间：2分钟
**操作**：
按照标准输出模板（第四节）组织内容，确保包含所有必需章节。

### Step 4: 个人解释生成 ⏱️ 预估时间：1分钟
**操作**：
用通俗易懂的语言重新阐述概念，包括：
- 类比或生活化例子
- 与已知概念的关联
- 为什么这个概念重要

### Step 5: 应用场景构建 ⏱️ 预估时间：1分钟
**操作**：
提供至少1个具体的、真实的、可验证的应用场景，包含：
- 场景背景
- 问题描述
- 该概念如何解决问题
- 实际效果或结果

### Step 6: 易混淆问题识别 ⏱️ 预估时间：1分钟
**操作**：
识别并澄清：
- 常见误解
- 与相似概念的区别
- 使用边界和限制条件
- 典型错误用法

### Step 7: 资料来源整理 ⏱️ 预估时间：30秒
**操作**：
收集并提供所有引用的资料来源链接，确保可访问和可核查。

### Step 8: 质量自检 ⏱️ 预估时间：1分钟
**操作**：
按照自检清单（第七节）逐项检查，不合格则返回修改。
