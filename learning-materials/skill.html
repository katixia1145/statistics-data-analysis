💡 一句话描述：

这是一个 AI 驱动的概念学习资料生成器，能够根据用户需求自动生成结构化、 多模态的**《统计与大数据分析》**课程学习材料，包括概念解释、数学公式、代码示例、练习题等。

🎯 触发条件 (Trigger Conditions)

🔔 自动触发场景

当用户的输入匹配以下模式时，Skill 会自动激活：

"帮我学习XXX概念" "生成XXX的学习资料" "解释一下《统计与大数据分析》中的XXX" "大数据分析中的XXX是什么" "我想了解XXX知识点" "整理XXX的学习笔记" "制定复习计划" "生成练习题"
⚠️ 触发机制说明：
  • 触发是基于语义匹配而非精确的关键词匹配
  • 即使用户的表达方式不同，只要意图相同就能触发
  • 系统会自动判断请求类型（概念学习/练习题/复习计划/对比）
  • 如果同时匹配多个 Skill，系统会选择最相关的一个

✨ 核心功能模块

📖 1. 概念解析生成

为指定概念生成完整的学习资料：

  • 中英文名称
  • 通俗解释 + 数学定义
  • 核心公式（LaTeX）
  • 直观理解（类比/图示）
  • 实际应用场景
  • 常见误区提醒

🗺️ 2. 知识关联图谱

构建概念间的关联网络：

  • 前置知识依赖
  • 并行对比概念
  • 进阶延伸方向
  • 实际应用链条
  • 学习路径推荐

✏️ 3. 练习题生成

创建多层次的练习题库：

  • 基础理解题（选择/填空）
  • 计算练习题（带步骤）
  • 应用分析题（案例）
  • 编程实现题（Python/R）
  • 难度分级系统

📅 4. 学习路径规划

制定个性化的学习计划：

  • 基于课程大纲的顺序
  • 标注重点难点
  • 时间分配建议
  • 里程碑检查点
  • 自适应调整策略

# [概念名称] ([English Name]) ## 📚 一、概念概述 [通俗易懂的解释] ## 🎯 二、核心要点 ### 2.1 数学定义 [严格的数学表达式] ### 2.2 关键公式 $$ [LaTeX 公式] $$ **变量说明：** - [符号]: [含义] ### 2.3 直观理解 [使用类比、图示等方式帮助理解] ## 💡 三、应用场景 ### 3.1 在统计分析中的应用 [具体例子] ### 3.2 在大数据分析中的应用 [具体例子] ### 3.3 实际案例 [真实数据集或业务场景] ## ⚠️ 四、常见误区 1. [误区1及纠正] 2. [误区2及纠正] ## 🔗 五、知识关联 ### 5.1 前置知识 - [概念A] - [概念B] ### 5.2 相关概念 - [概念C]：[关系说明] ### 5.3 进阶方向 - [高级主题1] ## 📝 六、练习题 ### 基础题 [题目] ### 计算题 [题目及数据] ### 编程实现 ```python # Python 代码示例 [代码] ``` ## 📚 七、推荐资源 - [教材/文章/视频链接]
📊 模板统计信息：
  • 主要章节：7个（概述 → 要点 → 应用 → 误区 → 关联 → 练习 → 资源）
  • 子章节：平均15-20个小节
  • 典型篇幅：3000-5000字（不含代码）
  • 包含元素：文字、LaTeX公式、代码块、列表、表格
  • 格式标准：GitHub Flavored Markdown + MathJax

⚠️ 使用注意事项

  1. 准确性优先
    所有数学公式和定义必须准确无误。如果对某个细节不确定，应明确标注。
  2. 循序渐进
    根据用户的水平动态调整内容的深度和广度。避免一次性输出过多信息。
  3. 实用导向
    强调在实际数据分析中的应用，而不仅仅是理论推导。
  4. 互动性
    鼓励用户提问和深入探讨。每个生成的资料都应该是对话的起点，而不是终点。
  5. 及时更新
    根据用户的反馈持续改进内容质量和生成逻辑。
