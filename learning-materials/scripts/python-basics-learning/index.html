在 VS Code 里怎么跑

① 跑整个文件

点右上角 ▶ 按钮，或按 Ctrl+F5。一次看完本章所有小节输出，适合第一遍通读。

② 逐段跑（推荐）

选中若干行，按 Shift+Enter，或右键 → Run Selection/Line in Python Terminal。理解「这一行到底做了什么」最快的方式。

③ 命令行

在 VS Code 终端里直接执行：

python 01_variables.py
前置条件：VS Code 需安装 Python 扩展（ms-python.python），并用 Ctrl+Shift+P → Python: Select Interpreter 选好解释器。 本套资料只用标准库，无需 pip 安装任何东西；Python 3.10+ 即可（match-case 需 3.10+）。 文件不使用 input()，所以不会卡在等待输入。

每章要点速查

章节必须记住的几条
01 变量 变量是贴在对象上的名字；= 是先算右边再让名字指向它； is 比对象身份、== 比值；判断 None 用 is None； copy.deepcopy() 才能彻底断开嵌套引用。
02 运算符 / 返回 float、// 向下取整、% 符号跟除数； and/or 返回操作数本身且会短路； and/or 优先级低于比较符；列表 += 是原地改、+ 是新建。
03 表达式 表达式一定有值；{x:.2f} / {x:>10} / {x:,} / {x=} 四个最常用； 切片左闭右开且越界不报错、[::-1] 反转； 空列表空字典空串在条件里都是假。
04 流程控制 缩进就是语法；elif 顺序错了分支会变死代码； for/while 的 else 只在正常结束时执行； break 只跳一层；range(a,b) 左闭右开。
05 函数 函数是一等对象；参数顺序「位置 → *args → 默认值 → 仅关键字 → **kwargs」； 别用可变对象当默认值（改成 None）；作用域 LEGB； 装饰器 = 接收函数返回函数，记得 functools.wraps。

常见报错对照表

报错典型原因怎么修
SyntaxError少括号 / 少冒号 / 用了中文标点 / if a = 1看箭头指向行的上一行结尾
IndentationErrorTab 与空格混用、缩进层级不对统一重排成 4 空格
NameError名字打错、还没赋值就用、跨作用域访问检查拼写与作用域
UnboundLocalError函数内给同名变量赋值，又在赋值前读它用 global / nonlocal，或换个名字
TypeError类型不匹配（"1" + 1）、参数个数不对type() 确认后做转换
ValueError类型对但值不对（int("abc")、解包个数不匹配）检查数据本身
IndexError下标越界，常见于 range 边界少一次打印 len() 核对
KeyError字典里没有这个键用 .get(k, 默认值) 或先 in 判断
AttributeError方法名拼错、对 None 调方法确认对象类型与拼写
ZeroDivisionError除数为 0（含 // %）先判断再除
RecursionError递归忘了终止条件补 base case，或改写成循环
